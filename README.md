# Dev Studies

**My journey in software development.**

Este repositório reúne meus estudos, exercícios práticos e projetos desenvolvidos durante minha jornada de aprendizado em Desenvolvimento de Software.

O objetivo é consolidar meus conhecimentos em programação, praticar a resolução de problemas e acompanhar minha evolução como desenvolvedor.

## Objetivos

- Desenvolver uma base sólida em lógica de programação.
- Aprender a escrever código organizado e legível.
- Praticar a resolução de problemas por meio de exercícios.
- Desenvolver conhecimentos em desenvolvimento de software e bancos de dados.
- Construir projetos práticos para meu portfólio.

## Tecnologias em estudo

- **JavaScript** — lógica de programação, estruturas condicionais, laços de repetição e funções.
- **C#** — fundamentos da linguagem e desenvolvimento de algoritmos.
- **MySQL** — fundamentos de bancos de dados e consultas SQL.
- **Git e GitHub** — versionamento de código e organização de projetos.

##  Conteúdo do repositório

O repositório é organizado para registrar minha evolução nos estudos, incluindo:

- Exercícios de lógica de programação.
- Algoritmos e resolução de problemas.
- Práticas com diferentes linguagens.
- Estudos de fundamentos de desenvolvimento de software.

## Evolução contínua

Este é um repositório em constante desenvolvimento. Novos exercícios, aprendizados e projetos serão adicionados conforme avanço na minha formação.

Acredito que a prática consistente, a curiosidade e a capacidade de resolver problemas são fundamentais para evoluir como desenvolvedor.

## Sobre mim

Sou estudante de Desenvolvimento de Software e estou construindo minha base técnica por meio de estudos, exercícios e projetos práticos.

Meu objetivo é evoluir continuamente, aprofundar meus conhecimentos e me preparar para oportunidades profissionais na área de tecnologia.

**Em constante aprendizado. Um passo de cada vez.** 🚀
